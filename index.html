คำชี้แจงและมาตราส่วนประเมิน

ประเมินสมรรถนะจากการสังเกตการปฏิบัติงาน การประเมินทักษะ หรือหลักฐานการทำงานจริง แตะปุ่มเลือกคะแนน 1–5 เพียงระดับเดียวต่อข้อ

5ดีเยี่ยมถูกต้อง คล่องแคล่ว สม่ำเสมอ เป็นแบบอย่างได้
4ดีปฏิบัติได้ถูกต้องด้วยตนเองเป็นส่วนใหญ่
3ปานกลางปฏิบัติได้ แต่ยังต้องได้รับคำแนะนำบางครั้ง
2ควรปรับปรุงปฏิบัติได้บางส่วน ต้องได้รับการกำกับดูแล
1เร่งด่วนยังไม่ได้มาตรฐาน ต้องพัฒนาอย่างใกล้ชิด

#วันที่ชื่อ-นามสกุลเพศหน่วยงานตำแหน่งผู้ประเมินรวมx̄ระดับ
ความคิดเห็นและข้อเสนอแนะ
การเชื่อมต่อ Google Sheet (บันทึกอัตโนมัติ)ยังไม่เชื่อมต่อ

วาง URL ของ Google Apps Script Web App (ลงท้ายด้วย /exec) ระบบจะส่งข้อมูลไปบันทึกที่ Sheet ทันทีที่มีผู้ส่งแบบประเมิน และ Dashboard จะดึงข้อมูลจาก Sheet มาแสดงจากทุกเครื่อง

วิธีตั้งค่า + โค้ด Apps Script (คลิกเพื่อดู)
  1. สร้าง Google Sheet ใหม่ → เมนู ส่วนขยาย › Apps Script
  2. ลบโค้ดเดิม วางโค้ดด้านล่าง แล้วกดบันทึก
  3. ทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่ › ประเภท เว็บแอป · ดำเนินการในฐานะ ฉัน · ผู้มีสิทธิ์เข้าถึง ทุกคน
  4. คัดลอก URL เว็บแอป มาวางในช่องด้านบน แล้วกดบันทึก (หรือใส่ไว้ในตัวแปร SHEET_URL ในไฟล์ HTML เพื่อให้ทุกเครื่องใช้ได้ทันที)
